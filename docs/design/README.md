# Design direction supplied by the user

These original reference images are retained for Phase 6. The assistant mascot is a friendly floating orb with leaves; the app logo is the dark green broom and leaf; the interface direction uses light, translucent panels and clear file review tables. They are visual references, not evidence of implemented functionality. Do not display fabricated storage savings or pretend a destructive action is reversible without a recovery record.

The current revision prioritizes operation reliability, approval clarity, working Finder links and honest recovery behavior. The floating mascot and larger visual redesign remain Phase 6.
