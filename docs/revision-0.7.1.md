# Tidy 0.7.1 — text-file removal and folder storage navigation

Simple requests such as “Remove the text files from my folder” now take an exact local path before model verification, model loading or skill routing. The preview checks every indexed path recursively for `.txt` and `.text` (case insensitive). Other extensions, Git paths, application/framework bundles, node_modules, target and .venv are excluded. The UI labels this an exact local filter, not AI inference. Native Trash still requires explicit review and approval, with existing source fingerprint and boundary checks. A maximum of 500 actions is shown per reviewed batch; apply then regenerate for remaining files.

The shortcut accepts only narrow whole-type requests. Extra conditions such as dates, named exceptions, combined actions or unfamiliar phrasing retain model investigation rather than silently broadening a request. For text-type requests routed incorrectly to named-file removal, investigation repairs that workflow choice and rejects non-text proposals, including continued proposals. This does not prove the model correctly interprets arbitrary additional conditions.

Storage now starts with authorized base folders. Volume capacity is available in an expandable section. Breadcrumbs and recursive contents bars support drilling down into children. Folder sizes sum indexed regular-file lengths across all descendants, including small files; directory metadata sizes are never used. These are logical content lengths, not physical or immediately reclaimable disk space. Partial scans and exclusions remain labeled. Empty directories are not indexed. Use Add a folder to authorize Home or other roots; no implicit entire-disk scan occurs.

Use this folder / Use folder selects a browsed descendant as a working scope and starts a metadata-only scan before Ask Tidy. It rechecks the parent root identity, relative path, symlinks and Git boundaries. The click authorizes indexing, not any file modification. Folder rollups are cached for one scope and invalidated using SQLite connection total changes, including moves that preserve file counts and byte totals.

Validation: Rust workspace and test targets compile offline; frontend TypeScript and production build pass; macOS debug app packaged. No inference, file mutation or functional tests run, per user preference. See the accompanying user checklist.
