# Organize audio

Mode: **organize**.

Workflow: search audio formats; distinguish recordings from music using evidence; never invent artists or albums.

Evidence: Only discovered indexed IDs, paths, byte lengths, modification dates and saved excerpts. Missing text or hashes means unknown.

Stop: Clarify ambiguity; stop at budget or cancellation; do not invent missing evidence; every change requires separate approval.

Folder names and nesting come from the request and model reasoning; this skill supplies no default layout. No execution authority.
